01扩散模型原理：以图片生成为例

先说清楚扩散模型到底在学什么。初期用于图片生成：
拿一张真实照片，逐步往上面撒噪声直到它变成纯雪花；再训练一个网络学会把这团雪花一步步还原回照片。 学会之后，从随机噪声出发就能「画出」新图。

图片：像素值被逐步加噪 纯噪声态
t = 0 · 原始图片
💡 点击播放：先看图片如何被噪声吞没（前向），再看它如何被逐步还原（反向）。

训练：只做一件事——预测噪声

取一份真实数据 x0，随机抽一个时刻 t，按调度表一次性加噪得到 xt； 让网络看着 xt 和 t，去猜这一步注入的噪声 ε 是什么。

目标 Lsimple(θ) = 𝔼t,x0,ε ‖ ε − εθ(xt, t)‖²
下标 t∼U{1,…,T}，x0∼真实数据，ε∼𝒩(0,I)。 这就是一个 L2 回归——每步都有标准答案。

生成：从纯噪声走到样本

前向是一步到位的闭式表达，反向没有闭式解，只能用学好的网络逐步近似：

前向 xt = √αt x0 + √(1−αt) · ε
反向 xt−1 ∼ pθ(xt−1 | xt)
生成时没有真实 ε 可参照，网络只能用自己估的 εθ 反推 x0 的估计，再前进一步。T 次迭代后噪声沉降，数据浮现。
一句话抓住本质：扩散不是在「画图」，而是在学习一个从噪声指向数据的向量场。 训练时用真实数据监督「这一步该去掉多少噪声」，生成时沿着这个方向反复走回数据分布。

三种主流形态

DDPM随机采样，T 步，经典基线
DDIM确定式，步数可大幅压缩
Flow Matching学直线路径，训练更稳

为什么需要 T 步

单步从纯噪声直接跳到数据太难。拆成 T 个小步，每步只需做「微小修正」， 学习任务变简单。代价就是推理慢——这也是后面 dLLM 只取几十步的原因。

文本的特殊性

图像像素是连续值，能直接加高斯噪声。文本 token 是离散的—— 「猫」加一点噪声还是「猫」吗？ 这正是第 05 节要解决的问题。

02扩散模型 vs GAN

同样是从随机数造出内容，GAN 靠对抗骗过裁判，扩散靠反复修掉噪声。 这个差别决定了它们各自失败在哪里、强在哪里。切换下面的标签页逐项看。

GAN：一个模仿者 vs 一个鉴定师

生成器 G 把噪声变成样本，试图骗过判别器；判别器 D 努力分辨真假。 两者在极小极大博弈中同时更新：

博弈 minG maxD 𝔼x∼pdata[log D(x)] + 𝔼z∼pz[log(1−D(G(z)))]
G 与 D 同时更新、互相拉扯，损失随对手变化—— 这就是非单调、无稳定信号的根源。

模型一次前向直接出结果。判据是「像不像真的」——一个相对的、动态的目标。

扩散：一个去噪匠

训练目标是预测这一步的噪声，是一个固定不变的回归任务：

回归 Lsimple(θ) = 𝔼t,x0,ε ‖ ε − εθ(xt, t)‖²
目标固定、每步都有真实噪声作标准答案，所以损失曲线单调下降—— 绝对的、静态的目标。

生成时迭代 T 步逐步还原，判据是「离真实数据还有多少噪声」——与对手无关。

关键分野：GAN 的目标随对手变化而变化；扩散的目标始终固定。 这一条几乎解释了后面所有的差异——包括为什么扩散稳、为什么 GAN 快。

训练是否稳定

与 dLLM 呼应：文本扩散也把「步数」作为可调旋钮， 用更少步换更低延迟——但不可能降到 GAN 的 1 步。

扩散占主导的场景

GAN 仍在守住的场景

实时人脸 / 风格化直播滤镜、实时换脸

超分辨率加速单步出结果即可满足
算力受限端侧T 步串行成本难以承受
2026 的默认选择：新项目做生成，默认选扩散——训练稳、覆盖好、可控性强。 只有在延迟硬约束（实时交互、端侧）时，GAN 或蒸馏后的少步扩散才是更合适的选择。 两者也在融合：用 GAN 做蒸馏、把对抗损失加进扩散训练，都是成熟做法。

专题 四条迁移路线：从连续到离散

扩散在图像上大获成功，但直接把高斯噪声搬到文本上行不通。 这一节讲清障碍在哪、四条路线分别怎么解，以及为什么最后是「掩码」赢了。

障碍：连续 vs 离散

图像的像素：连续

像素值是 [0,255] 的实数。128 + 0.1×ε 仍是合法像素， 「加一点噪声」天然有意义——邻域即相似。

文本的 token：离散

token 是从词表里挑一个。「猫」加 0.1 的噪声得到什么？ 「猫」+ε 在词表里没有对应项——这不是优化问题，是定义问题。

四条迁移路线

路线 A · 首试

嵌入空间做高斯扩散

把 token 映射成连续词向量，在嵌入空间跑标准高斯扩散，最后四舍五入回 token。代表：Diffusion-LM（2022）。

瓶颈：训练时处理连续值、生成时却要离散化， 「取整」这一步把训练与生成的连续性打断了。更麻烦的是，嵌入空间不是为扩散设计的—— 空间中相邻的点，未必是语义相近的词。

路线 B · 换编码

类比比特 Analog Bits

不直接用词向量，而把每个 token 编码成一串二进制位，把每个位当成 ±1 的连续值来扩散，采样后取符号恢复。

改进：避免了「任意词向量」的问题，配合自条件（self-conditioning）提升稳定性。 但仍要求「连续表示 → 离散」的最后一步转换。

路线 C · 换噪声

离散扩散 / 转移矩阵

不嵌入，直接在离散状态上定义马尔可夫破坏过程——用转移矩阵 Qt 规定「每个 token 以多大概率变成别的 token」。代表：D3PM（2021）。

关键实验结论：让 Q 基于词向量最近邻（相似词互变）的版本， 效果反而比「均匀随机变成词表里任意词」更差。结论很反直觉—— 词向量的相似度，并不构成扩散过程里有意义的「局部性」。

路线 D · 胜出

掩码扩散 Masked Diffusion

把「加噪」的离散对应物定义为替换成 [MASK]。 噪声越强 = 掩码率越高；全掩码 = 纯噪声。代表：LLaDA、MDLM。

为什么赢：① 无需嵌入空间，无取整断层； ② 目标与 BERT 的掩码语言建模同源，训练极其成熟； ③ 吸收态天然定义了「完全破坏」的终点，反向过程有明确的收敛目标。

把两种「加噪」并排看

拖动滑块看同一份数据在两种范式下怎么被破坏。注意本质差别：

连续扩散：数值被平滑扰动
性质渐变 · 可逆 · 加性
掩码扩散：token 被整块替换
性质跳变 · 吸收态 · 替换
左边每个像素都还在，只是变模糊；右边 token 要么完好、要么整个变成 [MASK]，没有中间态。

把「掩码」写成数学

迁移的关键动作只有一个：替换掉前向过程的定义。对比下面两组式子，注意「加噪」是怎么变的。

连续扩散（图像）

前向 xt = √αtx0 + √(1−αt) ε
状态 xt ∈ ℝd（连续）
噪声 ε ∼ 𝒩(0, I)　加性的
每一步都在原值上叠加一个小扰动，因此任意两步之间是平滑过渡，可逆且可微。

掩码扩散（文本）

前向 xt[i] = M　以概率 t
否则 xt[i] = x0[i]　以概率 1−t
状态 xt ∈ 𝒱L（离散）
每个位置独立地要么保持原文，要么整个变成吸收态 M。 没有中间态，不可微但无需可微——损失直接建在分类分布上。
两个定义的差别只有一处：图像用「加上高斯噪声」，文本用「以概率 t 替换成吸收态」。 其余全部保留——都要一个调度表、都要前向闭式、都要学一个反向去噪器、都要迭代采样。 架构骨架没动，动的是噪声的定义。
迁移的实质：不是「把图像扩散模型改小一点用来处理文字」， 而是重新定义什么叫噪声。图像里噪声是「高斯扰动」，文本里噪声是「掩码替换」。 框架（前向破坏 + 反向重建 + 迭代去噪）原封不动保留，只有噪声的定义换了。 这也是为什么 LLaDA 的损失函数长得像填空——它确实就是填空，只不过被放进了扩散的框架里。
一个观察：按这个定义，BERT 其实早就是一个「单步的扩散模型」—— 它用掩码破坏、预测被掩位置，只是没有把「多步迭代去噪」这件事做起来。 从 BERT 到 LLaDA，补上的正是「迭代」这一步。

04自回归语言模型 vs 扩散语言模型

同一个补全任务。左边逐字生成，右边并行去噪——看清它们「信息增长的方式」有多不一样。

自回归 · Autoregressive
0 / 12 步

每步只产出 1 个 token，写出即定稿。串行、因果注意力。

扩散 · Diffusion
0 / 6 步

每步同时预测所有位置，挑最自信的一批揭晓。双向注意力、可回改。

关键差异：自回归的「步数 = token 数」；扩散的「步数」是超参数，与长度解耦。 12 个 token 的句子，自回归必须跑 12 步，扩散 6 步就够——这是低延迟的来源。

05DLM 原理：前向与反向

上一节确立了一件事：文本的「噪声」就是掩码替换。这一节把这个定义展开成完整的双向过程。

Part A 前向过程：把句子「打码」

训练前先定义怎么破坏数据。对文本的破坏方式极简——按比例把 token 换成 [MASK]。

保留的原始 token 被替换成 [MASK]
训练目标：模型看到打码后的句子，要还原所有 [MASK] 位置的原文。 每个位置被遮住的概率独立，且都等于 t。
与 BERT 的区别在这里：BERT 用固定掩码率（如 15%），且不做生成。 LLaDA 用随机掩码率 t ~ U[0,1]，让同一目标覆盖从「几乎没遮」到「全遮」的全部难度， 于是模型学会从纯噪声起步生成——这才是「扩散」而非「填空」。

Part B 反向过程：迭代显影 · 且能反悔

这是整套机制的核心。从全掩码起步，反复「预测 → 挑最自信的揭晓」。 下面这个案例会走到第 5 步时主动推翻自己：把已经写出的字重新涂黑，再改掉。

本步模型对每个 [MASK] 位置的置信度

① 并行预测

一次前向，所有掩码位置同时得到词表分布。这是与自回归最本质的分野。

② 置信度排序

按最高概率排序，只揭晓最靠前的一小批。低置信位置留到后续步再定。

③ 可回改 Remasking

已揭晓的位置可以重新涂黑，让模型带着更充足的上下文重判。自回归做不到这一点。

为什么能低延迟：自回归 8 个 token 要 8 次前向；这里 8 个 token 只需 6 次前向。 在 batch size 1~4 的场景下，实测可带来 2~10× 的生成延迟下降。
可回改意味着什么：自回归一旦写出 token，后面的 token 只能在这个前提下续写，错误会沿链条放大。 扩散允许「全局重审」——这也是它在长链推理、代码生成这类需要回溯的任务上被看好的原因。

06训练目标

LLaDA 到底在优化什么？并不神秘——就是掩码语言建模损失，加了一个 1/t 权重。

损失 L(θ) = − 𝔼t∼U[0,1],
x0,xt [ 1/t · Σi : xt[i]=M log pθ( x0[i] | xt ) ]
等价 = − (1/t) · Σi∈掩码位 log pθ(x0[i] | 未掩码的上下文)
读法：把「带权重的交叉熵」在自己造的打码数据上求期望。 它同时是负对数似然的变分上界，因此 LLaDA 是有原则的生成模型，不只是「借用了填词技巧」。

符号表

θ模型参数
t掩码率，每步从 U[0,1] 重新采样
x0干净的真实序列，长度 L
xtx₀ 的加噪版本：每位独立以概率 t 变 M
M吸收态 [MASK]；一旦变 M 就不再变
Σi∈掩码位只对被打码的位置求和
1/t权重：低掩码率下把单点损失放大
pθ(·|·)模型在每个掩码位给出的词表分布

为什么权重是 1/t

掩码率 t 越小，被遮的位置越少，参与求和的项也越少。若不加权， 「几乎没被遮」这类简单样本的梯度会被淹没，模型学不到低噪声区间的还原能力。

直觉 掩码位数量 ≈ t·L， 乘以 1/t 后 ≈ L（与 t 无关）

归一化之后，每个噪声等级获得同等权重——而低噪声正是反向生成最后几步的战场。

同一目标贯穿始终：预训练和 SFT 用同一个损失。SFT 时只把 response 段打码、prompt 保持可见， 模型就自然学会「给定指令生成回复」，无需换目标函数。

07最新技术：2026 年的四条主线

机制讲完了，看它现在进化到哪。dLLM 这一年从研究走进了工程，四条主线最值得关注。

① 块扩散成为部署标配

不整句并行，而是把序列切成固定大小的块（典型 32 token）：块内并行去噪、块间按序推进。 这样既保留了并行的速度，又拿回了自回归的长序列稳定性。

结构 [ 块1 ] → [ 块2 ] → [ 块3 ] → ⋯　块内并行，块间串行
块一旦去噪完成就提交进 KV cache，下一块在此基础上初始化。

② 从零训练 → 改造自回归模型

从零预训练成本太高。2026 的主流做法是拿已训练好的自回归模型做初始化， 再用扩散目标继续训练——复用同一套 transformer 主干，成本大幅下降。

④ 后训练与推理加速

采样轨迹本身成了优化对象——把每一步去噪当作决策来强化学习：

定位很明确：不是替代自回归。Google 自己的说法是 「自回归 Gemma 4 仍是高质量生产输出的标准」，DiffusionGemma 面向 延迟敏感的本地交互场景——行内编辑、快速迭代、非线性文本。

技术上它采用块自回归扩散：256 token 块内并行去噪，块完成后提交 KV cache， 再以新画布处理下一块——把「并行的速度」和「串行的稳定」缝在一起。

一个反方观点，值得记录：2026 年的讨论中也有明确唱反调的声音——有人主张 「离散扩散语言模型还不是自回归语言的替代品」。同年 ICML 的杰出论文 《The Flexibility Trap》更进一步质疑：dLLM 引以为傲的「任意顺序生成」到底有多少真实价值。 这一节列的是技术进展，不等于已经取得全面优势——机制上能不能赢，和当下有没有赢，是两件事。
