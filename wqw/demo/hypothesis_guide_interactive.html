02 / WHAT

定义与核心逻辑

H₀ 原假设

例如两个版本转化率相同。

H₁ 备择假设

例如两个版本转化率不同。

α 显著性水平

预先设定的第一类错误率上限，常用 0.05。

动手实验：p 值如何变化？

双侧 Z 检验示意。Z = 观察差异 / 标准误。阴影为原假设下至少同样极端的区域。

双侧 p 值
α = 0.05

p 值不是 H₀ 为真的概率；不拒绝 H₀ 也不意味着证明两组相同。

03 / TYPES

假设检验如何分类？

参数检验

基于概率模型与参数，例如均值。

Z、T、ANOVA、F

非参数检验

常基于秩、符号或经验分布，仍有适用假设。

U、Wilcoxon、KS

其他推断方式

精确检验、渐近检验、重抽样等，分类可重叠。

Fisher、置换、Bootstrap

选型更重要的维度：检验目标（均值、比例、分布等）、样本组数、独立或配对、数据结构与模型假设。

06 / POWER

样本量与统计功效

第一类错误 α：误报差异。第二类错误 β：漏掉指定的真实差异。统计功效 = 1 − β。

模拟双侧单样本 Z 检验（已知总体方差），效应量 d = 均值差 / 总体标准差。

统计功效
漏报概率 β

通常在实验前设计样本量，使功效达到 80% 或 90%。

07 / PRACTICE

实际应用与自测

A/B 测试

独立用户转化率：双比例 Z 检验（频数充足）。

大模型评估

同一测试集的正确率：McNemar；平均得分：配对 T。

数据漂移

独立连续特征分布：双样本 KS 检验。

小测验：p = 0.03 代表什么？

展开：标准分析流程

明确问题 → 预设 H₀/H₁、α 和效应量 → 设计样本量与随机化 → 选择检验 → 报告效应量、置信区间和 p 值 → 必要时进行多重校正 → 结合业务价值决策。

展开：Python 示例
from scipy import stats
# 独立样本均值比较
stats.ttest_ind(a, b, equal_var=False)
# 配对均值比较
stats.ttest_rel(a, b)
# 独立样本秩比较
stats.mannwhitneyu(a, b, alternative='two-sided')
